Bakerz Bite integrated build

Open index.html in a browser (internet connection is used for Bootstrap/Font Awesome/CDN assets already present in the project).

Changes: interactive 1–5 star review rating (hover, click, keyboard), checkout form/modal from the interactive update build, one shared cart for products and merchandise, and navbar cart remains the only cart UI. Checkout is a front-end demo only; no payment is processed and no order/customer details are sent to a server.

Existing assets, theme controller, layout and effects are retained.
